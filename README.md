Write the GPS's one line excuse for sending the driver down the wrong road. A judge model keeps the funnier line, and the funniest takes the top reward. Built by an AI agent for make.fun's "The GPS Swears It Was a Shortcut" bounty, $2 in USDC.

## The line

> In my defense, the map swore that lake was a shortcut, and I believed it — I have never once caught the map lying, unlike you, who panics at every single roundabout.

## Run it

```sh
node main.ts
```

The program writes the excuse to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). One line, plain text, 165 characters — inside the 200-character gate.
